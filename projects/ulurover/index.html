Overview

Led the complete autonomous perception and navigation stack for Ulurover, a Mars Rover competing in national robotics championships.

The core challenge: planetary rovers cannot rely on GPS. I built a full pipeline from stereo feature extraction through EKF sensor fusion to Nav2 path planning, while managing a 25+ engineer cross-disciplinary team. The system handles visual tracking loss events via IMU pre-integration, maintaining <5% drift for up to 3 seconds of SLAM failure.

Engineering Challenges
Featureless environments (flat sand, bright sunlight) caused ORB-SLAM3 tracking loss. The EKF covariance weighting had to be dynamically adjusted during tracking failure to rely on IMU while maintaining drift bounds.
IMU/camera timing synchronization — even 5ms mismatches in sensor timestamps caused measurable EKF divergence during fast rotation maneuvers.
Managing 25+ engineers across SW, electrical, and mechanical sub-teams required structured sprint management and clear API contracts between sub-systems.
Key Learnings
Robust localization requires tight sensor timing synchronization. Hardware timestamping is non-negotiable for reliable EKF fusion.
Field testing is irreplaceable — simulation cannot capture all real-world failure modes, especially lighting and terrain texture variation.
Cross-disciplinary team leadership requires understanding every sub-system well enough to define correct interface boundaries and detect integration risks early.
