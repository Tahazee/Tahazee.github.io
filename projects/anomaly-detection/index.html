Overview

This research project explores whether unsupervised anomaly detection models can generalize across manufacturing conditions — learning the normal data manifold from defect-free samples only.

The core insight: a well-trained autoencoder will reconstruct normal textures accurately, but fail on anomalous regions — producing high reconstruction error exactly where defects exist. SSIM loss captures structural distortions that pixel-wise L2 misses, significantly improving localization precision.

Key Learnings
Composite loss functions that capture multi-scale structure (SSIM) significantly outperform pixel-wise L2 for anomaly localization. The choice of reconstruction loss matters more than architecture.
Autoencoders can reconstruct defects too well if the latent space is too large — defeating the anomaly detection objective. Bottleneck capacity is a key hyperparameter.
Dataset quality dominates: MVTec AD's clean, consistent images make it easier than real production environments where lighting, scale, and texture vary.
