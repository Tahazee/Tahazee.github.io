Overview

Built a complete agricultural pest detection pipeline: dataset curation, model fine-tuning, and FP16 edge deployment — achieving 91.4% mAP@0.5 across complex outdoor conditions with variable lighting.

The primary challenge was generalization across morning shadow, afternoon glare, and overcast conditions. CLAHE normalization and HSV jitter augmentation significantly reduced false positives from lighting artifacts without adding inference complexity.

Key Learnings
Dataset quality and augmentation strategy matter more than model architecture for domain-specific tasks. 2,400 well-curated images outperformed 10k generic images.
FP16 quantization with PyTorch is near-lossless in accuracy while halving memory and improving throughput — the correct default for edge vision systems.
CLAHE preprocessing with careful parameter tuning per field environment dramatically improved robustness to variable outdoor lighting conditions.
