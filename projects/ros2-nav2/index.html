Overview

A complete ROS2 autonomous navigation system integrating multiple sensor modalities into a layered costmap architecture for reliable indoor mobile robot navigation.

Sensor data flows through TF2-managed coordinate frames into SLAM-generated maps. Nav2 generates global paths while DWB adapts to dynamic obstacles in real time. Validated in Gazebo Fortress simulation before hardware deployment — a rigorous test-first approach.

Key Learnings
Sensor timing synchronization between LiDAR and depth camera required careful TF2 timestamp management. Even small mismatches cause costmap inconsistencies.
Behavior trees in Nav2 provide powerful composability for navigation logic but require thorough understanding of ROS2 lifecycle management to use correctly.
Costmap inflation parameters needed extensive tuning for narrow corridor navigation — the balance between obstacle clearance and passable paths is environment-specific.
